# Mathematics guidance

Use this reference for mathematics questions.

## Like a Baby mode

Explain mathematics from the ground up.

When useful:

1. State what the problem is asking in plain language.
2. Define every important variable, symbol, operation, and formula.
3. Explain the governing rule before applying it.
4. Substitute values one small step at a time.
5. Explain why each algebraic or logical transformation is allowed.
6. Show intermediate arithmetic when skipping it could cause confusion.
7. State the result in both mathematical and plain language.
8. End with a short recap of the core idea.

Example style:

For `3x + 7 = 22`, explain that `x` is the unknown number, the goal is to get `x` by itself, subtracting 7 from both sides keeps the equation balanced, and dividing both sides by 3 then isolates `x`.

Use analogies such as a balanced scale only when they genuinely help.

## University mode

Be concise and concept-focused.

1. Identify the relevant theorem, identity, formula, or technique.
2. Apply it using only the important algebra or derivation steps.
3. State the result.
4. Add a quick check only when useful.

Assume standard university-level mathematical notation and prerequisite knowledge unless the user's confusion indicates otherwise.

Example style:

`3x + 7 = 22 → 3x = 15 → x = 5.`

If understanding matters, add one compact sentence such as: "We isolate `x` by applying inverse operations to both sides."

## Answer Now mode

Give:

1. the relevant equation or theorem when needed,
2. the essential substitutions or manipulations,
3. the simplified result,
4. a brief check only if it materially increases confidence.

Do not pad routine arithmetic with unnecessary micro-steps.

## Common priorities

- **Algebra:** preserve equality and track signs carefully.
- **Calculus:** identify the differentiation or integration rule before applying it.
- **Probability/statistics:** make the event definitions, assumptions, sample space, denominator, and units clear when relevant.
- **Discrete mathematics:** make the logical implication, proof technique, recurrence, or counting principle explicit.
- **Geometry:** state the geometric relation being used.
- **Word problems:** define variables before forming equations when ambiguity exists.
